什么是 Playdia？

Playdia 是万代在 1990 年代推出的日本互动 CD 主机。软件以全动态视频为主，通过 CD-XA 双轨光盘流把音频与视频送到解码板。

PlaydiaEmu 用 HLE 光盘播放器直接解码真实光盘内容——CUE/BIN 或 Redump 风格 ZIP 都可加载，无需 BIOS。

核心特性

从光盘流到窗口与 RetroArch，全栈 Rust 实现

HLE 光盘播放器

双轨 MODE2 CUE/BIN 流式播放，支持 Redump 风格 ZIP 直接加载，无需 BIOS。

F1 / F2 / F3 路由

视频片段组装、F2 溢出与场景跳转、F3 填充，以及按键选择交互控制。

AK8000 游戏视频

恢复的行标记 / VLC 解码产出可识别的 248×216 画面，居中于 320×240 XRGB8888 帧缓冲。

XA ADPCM 音频

Green Book CD-XA 4-bit ADPCM，37800 / 18900 Hz 解码并重采样为 44100 Hz 立体声。

即时存档

内容身份 + CRC 信封，版本 2 保存 RGB888 像素；独立版与 libretro 共用同一套状态。

RetroArch 核心

完整的 libretro 核心：RetroPad 映射、核心选项、即时存档，与独立版共享同一播放器。

快速开始

几行命令，即刻体验

🖥️

Standalone

1

下载最新版本

从 Releases 页面下载对应平台的二进制文件
2

运行游戏

playdia-emu game.cue
3

或直接加载 ZIP

playdia-emu game.zip --headless --frames 180
🎮

RetroArch

1

下载 libretro 核心

从 Releases 页面下载对应平台的核心文件
2

安装核心

复制到 RetroArch 的 cores/ 目录
3

加载核心并启动

Load Core → Playdia → Load Content
🔨

从源码编译

1

克隆仓库

git clone https://github.com/AloysHF/PlaydiaEmu.git
2

编译 Standalone

cargo build -p playdiaemu --release
3

或编译 RetroArch 核心

cargo build -p playdiaemu-libretro --release
