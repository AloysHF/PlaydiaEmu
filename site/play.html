在线试玩 Playdia 游戏

选择本机上的光盘镜像（.iso，或包含 CUE/BIN 的 .zip），由 EmulatorJS 与 PlaydiaEmu WebAssembly 核心在浏览器中直接运行，无需安装，也不需要 BIOS。

首次启动需要下载 WebAssembly 核心，请稍候。

选择光盘镜像

支持单文件 .iso，或包含 CUE + BIN 的 .zip。Playdia 光盘为双轨 MODE2，CUE 与 BIN 必须打包在一起。

也可以把镜像拖进窗口。文件只在浏览器本地处理，不会被上传。可玩的游戏见 兼容列表。

无法启动在线模拟器

EmulatorJS 运行时未部署（缺少 data/loader.js）。请通过 Pages 部署流程生成 site/data，或直接使用独立版模拟器。

方向键 移动 X / Z A / B 键 Enter START Shift SELECT 支持手柄与手机触屏

在线试玩使用 EmulatorJS， 即时存档只保存在浏览器本地。游戏数据不随本站分发，请使用自己合法持有的光盘转储。想离线游玩？从 Releases 下载独立模拟器或 RetroArch 核心。
